    02 ENGINEERING PROJECT

    A city in motion.
    An agent in the loop.

    A Java ride-dispatch simulator with concurrent scheduling, a live operations map, and an assistant that can query drivers and submit orders through tools.

    JavaLangChain4jConcurrency
    Source code ↗
    Under the hood +

    Three concurrent loops handle request generation, dispatch, and ride completion. Tool calls connect the assistant to current driver state and the running dispatch queue. CAS-based state transitions and in-memory cache, lock, and index simulations explore coordination and consistency.

    Educational simulator; cache and database patterns are modeled in memory.
